# 📷 Photos

Drop finished-drink photos here, named by the cocktail's slug:

```
photos/queens-park-swizzle.jpg
photos/mojito.jpg
```

Cards in `wiki/` reference them as `../photos/<slug>.jpg`. The image links already exist in
the seed cards, so a photo will appear automatically once you add a file with the matching
name. Photos are optional — a missing one just shows a broken image, not an error.
